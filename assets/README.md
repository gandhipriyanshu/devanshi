# Project Assets & Design Direction (Phase 0)

## 🎨 Theme & Mood
* **Mood:** Warm, dreamy pastel & cozy celebration
* **Audience:** Devanshi (optimized for mobile display)

## 🌈 Color Palette
* `--bg-soft-blush`: `#FFF5F5` (Soft background)
* `--color-primary-pink`: `#FF7597` (Accents, highlights, celebration)
* `--color-frosting-vanilla`: `#FFF8E7` (Cake tiers, letter paper)
* `--color-flame-gold`: `#FFB703` (Candle flame glow)
* `--color-text-deep`: `#2E222A` (Legible, warm charcoal text)
* `--color-pastel-lilac`: `#EADCF0` (Envelope & secondary accents)

## 🔤 Typography
* **Handwritten Font:** [Caveat](https://fonts.google.com/specimen/Caveat) (`'Caveat', cursive`) — used for personal notes, envelope, and headlines.
* **Clean Font:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (`'Plus Jakarta Sans', sans-serif`) — used for UI buttons, hints, and body reading.
